# Simple SDK Semantics — Language-Neutral

Human/developer operations:
- `create_entity`
- `create_application`
- `pair_device`
- `register_asset`
- `record_event`
- `export_entity`

Verification/revocation:
- `verify_pairing`
- `verify_export`
- `revoke_device`

This profile does not expose direct settlement, payment, verified-rights, corporate-capital or sovereign-authority mutation.

`Export My Entity` means a signed portable Entity export.

`Move My Entity` remains outside this first external conformance target until provider-to-provider import and retained controller/root continuity are qualified end to end.
