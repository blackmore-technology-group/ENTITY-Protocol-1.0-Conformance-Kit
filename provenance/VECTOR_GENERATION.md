# Vector Generation Provenance

The fixed vector files in this kit were generated by Blackmore Technology Group from an **isolated synthetic ENTITY reference state** solely to establish observable valid/invalid protocol examples.

Controls applied:

- no BTG production Entity, user, customer or application authority was used;
- all Entity identities in the vectors are synthetic and have no production authority;
- no production SQLite database, private state or user/business source data is included;
- the temporary vector-generation state was deleted after vector creation;
- the vector-generator implementation is **not included** in this clean-room repository;
- the BTG reference implementation is **not included** in this repository;
- each frozen vector is individually SHA-256 committed by `vectors/VECTOR_MANIFEST.json`;
- the sealed kit manifest signs the content hashes of the published package.

The vectors are test inputs, not an independent implementation.

A genuine external PASS requires a separately authored implementation to reproduce the required outcomes from the public specification alone.
