# External Conformance PASS Criteria

A full ENTITY Protocol 1.0 external interoperability PASS requires:

| Gate | Required |
|---|---|
| Public specification only | PASS |
| Independent implementation | PASS |
| No BTG runtime dependency | PASS |
| All required valid vectors accepted | PASS |
| All required invalid vectors rejected | PASS |
| Entity identity verification | PASS |
| Principal binding verification | PASS |
| Asset/event interpretation | PASS |
| Lineage interpretation | PASS |
| Domain/service verification | PASS |
| BTG → Independent communication | PASS |
| Independent → BTG communication | PASS |
| Sovereign export verification | PASS |
| Same protocol interpretation | PASS |

If any gate is missing, report the exact partial scope rather than claiming full external qualification.
