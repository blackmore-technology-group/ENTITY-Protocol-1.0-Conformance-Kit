# Independent ENTITY Protocol 1.0 Conformance Report

The independent party authors this report.

Required evidence:
- implementation language/version;
- source repository commit/hash;
- developer/organization and date;
- Protocol 1.0 hash;
- conformance kit hash/tag;
- test-vector results;
- live interop results;
- failures and limitations;
- implementation build SHA-256;
- signed declaration.

BTG may hash/link/ingest the completed report but should not write the independent party's conclusions for them.
